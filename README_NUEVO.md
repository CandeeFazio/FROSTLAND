# FROSTLAND — Rediseño completo

## Iniciar
1. Abrí PowerShell dentro de esta carpeta.
2. Ejecutá `npm install`.
3. Confirmá que exista `.env`. Si no existe: `Copy-Item .env.example .env`.
4. Completá las credenciales de Mercado Pago dentro de `.env`.
5. Ejecutá `npm start`.
6. Abrí `http://localhost:8000`.

## Novedades
- Paleta marrón, beige y negro.
- Carrusel de portada con fotografías.
- Sección Inicio, Carta, Cuenta y Administración.
- Carta de sabores ordenada, con buscador y disponibilidad.
- Panel de sesión renovado.
- Estados editables: recibido, confirmado, en proceso, terminado, en camino, entregado y cancelado.
- Chat interno asociado a cada pedido para clientes y administradores.
- Panel de stock, tamaños, precios, máximo de sabores y sabores conservado.

## Nota sobre las fotos
Las imágenes del carrusel se cargan desde Unsplash, por lo que requieren conexión a internet. El resto de la aplicación puede ejecutarse localmente.
