# FROSTLAND - Inicio rápido

1. Abrí PowerShell en esta carpeta.
2. Ejecutá `npm install`.
3. Ejecutá `npm start`.
4. Entrá a `http://localhost:8000`.

La aplicación inicia sin productos ni sabores. Ingresá como administradora con los datos de `CREDENCIALES_ADMIN_PRIVADAS.txt` y cargá todo desde Administración.

Las imágenes subidas se guardan en `data/uploads`. Las cuentas, pedidos, horarios y productos se guardan en `data/db.json`. No borres la carpeta `data` si querés conservarlos.
